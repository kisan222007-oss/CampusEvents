# CampusEvents 🎓

A college event management system built with Flask, MySQL, HTML, CSS, and JavaScript.

## 🚀 Live Demo

[Visit CampusEvents](https://campusevents-ruzn.onrender.com)

## ✨ Features

- Student registration and login
- Admin and Organizer login
- Event creation, editing, and deletion
- Student event registration
- Organizer event management
- Event search by name or organizer
- Student registration management
- Admin dashboard
- Organizer management
- Active/Inactive organizer accounts
- Profile management
- Registration confirmation emails
- Password reset with OTP

## 🛠️ Technologies

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
- NumPy
- Flask-Mail

## ☁️ Deployment

- **Frontend/Backend:** Render
- **Database:** Aiven MySQL
